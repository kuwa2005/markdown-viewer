# Hearing Log — GFM仕様書の分割 & GitHub 連携

## Q1: 出力形式
- **背景**: AIエージェントがコーディング中に参照しやすい形式が欲しい
- **質問**: 章ごとに分割 or 1ファイル？
- **回答**: 章ごとに分割。人が読む用ではなくAIエージェントが利用しやすい形式。言語は英文のまま。

## Q2: 含める範囲
- **背景**: GFM仕様は9000行超の長文。エージェントが効率的に参照できる構造が必要
- **質問**: 全文 or 抽出？
- **回答**: 英文のまま全文。概要・詳細を分割ファイルとして、リンクで辿れるコーディングエージェント向け形式。

## Q3: 保存先
- **回答**: `gfm-specifications/` ディレクトリ

## Q4: GitHub 連携 — 初期コミット
- **背景**: GFM仕様書の分割・差異分析が完了。GitHub で管理を開始したい
- **質問**: コミット対象は？
- **回答**: gfm-specifications/ + 既存変更分（このセッションで作成した全ファイル）

## Q5: GitHub 連携 — Issue 登録
- **背景**: GFM差異分析で P0〜P2 の6件の課題を特定
- **質問**: Issue の登録方法は？
- **回答**: 差異分析の P0〜P2 をそのまま Issue として6件登録
